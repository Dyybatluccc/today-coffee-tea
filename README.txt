TODAY COFFEE TEA - WEBSITE GIỚI THIỆU

1. Cách chạy
- Giải nén thư mục.
- Mở thư mục today-coffee-tea bằng VS Code.
- Mở file index.html bằng trình duyệt hoặc dùng extension Live Server.
- Cần kết nối Internet để tải Google Fonts, Font Awesome và AOS từ CDN.

2. Các trang
- index.html: Trang chủ
- about.html: Giới thiệu
- menu.html: Thực đơn mẫu
- gallery.html: Thư viện ảnh
- contact.html: Liên hệ và form minh họa

3. Công nghệ
- HTML5 và CSS3
- Font Awesome CDN
- Google Fonts CDN (Be Vietnam Pro, Playfair Display)
- AOS CDN để tạo hiệu ứng khi cuộn trang

Lưu ý: AOS cần một đoạn JavaScript ngắn để khởi tạo hiệu ứng. Đây là phần duy nhất có JavaScript trong dự án. Menu điều hướng trên điện thoại, liên kết trang và hiệu ứng hover dùng HTML/CSS. Form liên hệ chỉ minh họa giao diện; chưa có máy chủ để nhận và lưu dữ liệu.

4. Nội dung cần chỉnh sửa
- Thay địa chỉ, số điện thoại, email mẫu bằng thông tin thật.
- Menu và giá là dữ liệu minh họa, cần thay theo thực đơn thực tế.
- Ảnh quầy và ly nước được lấy từ ảnh người dùng cung cấp. Có thể bổ sung ảnh riêng cho từng món và từng góc quán trong thư mục images.
